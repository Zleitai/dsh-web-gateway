# Alpha 验收记录

0.2.0-alpha.2，固定 DSH 0.1.2-rc.1。该独立手机 PWA 原型已冻结，
验收记录不代表兼容后续 DSH 版本。

## Windows 本地已执行

- TypeScript：协议、插件、中转、手机网页构建。
- Vitest：15 项通过，覆盖加密双向通信、身份伪造、乱序/重放/篡改、二维码过期和一次性使用、
  未授权/撤销、工作区隔离、请求去重和冲突、待确认请求核对、
  审批首答、历史投影与重连序号缺口。
- 真实 WebSocket：邀请配额、配对、加密业务、重连去重、撤销、
  伪造电脑、可重试离线状态、坏手机与其他设备隔离。
- Playwright：Chromium/Android 尺寸、WebKit/iPhone 尺寸，
  配对、创建、文字、流式回复、审批、断线重连、模拟网络离线、中转重启、刷新和撤销；
  截图与横向溢出检查。
- 真实 DSH 发布包、临时 DSH_HOME：插件加载、原生浏览器认证/同源校验、
  二维码与电脑确认、工作区和会话、桌面/手机同一会话继续、
  流式与请求 ID、审批原生审计、结构化问题、取消、历史，
  运行中卸载插件保留任务与会话。
- DSH 命令行离线安装插件、注册 bundle、卸载通过；发行包解包到源码目录外实际加载通过。

模型网络层使用确定性测试适配器，DSH 会话/Agent/控制器/持久化/权限为真实服务。
自动化截图使用测试内容，不采集用户会话。

## 发布门槛：仍未完成

- iPhone Safari、Android Chrome **实机**扫码、聊天、审批、锁屏、
  蜂窝/Wi-Fi 切换、浏览器被系统回收后的恢复。
- 真实手机 + 真实模型 + 桌面同时回答的完整体验。
- 默认中转限量邀请码试运行、长期连接和运维告警。
- 本机没有 Docker；容器构建与运行需在 CI/部署环境验证。
- 已提供 CI 工作流，但尚未 push 执行，不宣称 CI 已绿。

完成这些门槛前，不替换实际运行的旧服务，不承诺支持全部设备、
全部 DSH 版本或生产 SLA。

实机记录应包含设备/系统/浏览器版本、DSH/插件版本、测试时间与网络，
确认已提交消息不丢失/不重复、审批归属正确、撤销生效、日志无秘密和正文。
