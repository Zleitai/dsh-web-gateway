# 安全模型与协议 v1

## 身份与加密

电脑和手机分别持有身份私钥。二维码固定电脑公钥；电脑人工确认固定手机公钥。
五分钟配对秘密为 32 随机字节，只在 URL fragment 内传递，手机读取后立即移除。
每张二维码只有一个候选公钥可领取，拒绝或确认后消费。
已授权手机每次重连仍须证明其私钥。撤销关闭该设备的所有连接。

libsodium crypto_box 认证握手中的 channel、challenge、临时 crypto_kx 公钥。
crypto_kx 派生双向密钥，再使用两条 secretstream 通信。
每次连接使用新的临时密钥、挑战和 stream header。
错误身份、连接绑定、重复握手、乱序、篡改和重放均拒绝。
坏手机的数据只关闭对应手机通道。

中转可见路由、连接时间、网络地址、长度与密文，正常情况下不能读业务正文。
网页发布链路、插件、浏览器和电脑仍可信；不保护被篡改的客户端。
手机身份密钥存在 IndexedDB，电脑身份/授权在插件 SQLite 中，
依赖 OS/浏览器权限，没有承诺磁盘加密或账号恢复。

## 白名单与权限

请求统一包含 v=1、UUID requestId、method 和该方法允许的参数。
会话 ID 兼容 DSH 原生的带前缀标识，所有 JSON 参数严格验证。
只提供 workspaces.list；sessions 的 list/create/history/watch/unwatch/send/cancel；
interactions 的 list/answer。没有任意路径、通用 RPC、凭据或全局设置接口。

配对确认、共享范围、设备列表和撤销在已认证的电脑管理页操作。
会话请求逐次验证设备和共享工作区归属。默认共享为空。
共享变更会断开现有手机；原生 DSH 工具权限仍然有效。

历史保留 seq/endSeq。内部审计、推理和工具参数不作为聊天正文转发。
审批卡片显示工具与原因，完整参数在电脑查看。
审批绑定 sessionId 和 interactionId，仅能 allowed-once 或 rejected；
问题校验题目、选项和多选限制。第一次有效回答生效，其余明确过期。

## 提交与恢复

调用副作用之前先存 pending 回执，键为设备公钥和 requestId。
内容不同但 requestId 相同会拒绝；完成回执复用原结果。
只存请求哈希和精简结果，不重复保存聊天。
创建/发送走 Session Controller，确认前使用官方 sessions.flush 持久化。

崩溃留下 pending 回执时核对已入队/已消费的 DSH 请求 ID，
找不到则 RESULT_UNCERTAIN，不自动重发。核对最多额外十页，
未找到不等于从未执行。回执不自动过期，避免过期后重复执行。

断线/卸载不主动取消任务。重连先读取状态，再分页补齐断线前后的事件缺口。
手机聊天只在内存；刷新后重新读取 DSH。PWA 缓存只包含静态界面资源。
锁屏不保证浏览器持续联网。

历史窗口按预算缩小并保留更早分页。单条记录过大时明确失败，
不截断后伪装完整；超大输出请在桌面查看。

## 运行数据

中转数据库只存电脑标识、注册 token 哈希、注册时间、邀请码哈希/配额。
不持久化聊天/审批/文件正文，不引入第三方分析。
请勿在公开 issue 附上身份密钥、浏览器数据、二维码或真实会话诊断。
